# 掌上艾欧泽亚

Windows x64 客户端，使用 .NET MAUI、HybridWebView、Vue 和 WebGL2。支持查看盛趣角色信息和石之家只读信息、预览角色全身和面部、导出 PNG 及检查游戏版本。

## 构建

需要 Windows 10 2004 或更新版本、WebView2 Evergreen、Node.js 24 和 .NET SDK 10.0.402。MAUI Windows 工作负载集固定在 `global.json`，宿主使用 MAUI 10.0.110。Windows SDK 构建工具随 NuGet 依赖还原。

```powershell
dotnet workload install maui-windows
.\scripts\build-windows.ps1
```

脚本执行前端构建、NuGet 锁定恢复、Windows 编译和离线核心测试。运行 `src\Lodestone.App\bin\Release\net10.0-windows10.0.19041.0\win-x64\Lodestone.App.exe`。使用 `-Publish` 可生成自包含的应用目录，发布文件位于同一输出树下的 `publish`。

## 核对 Windows 预览

1. 完成盛趣登录并选择角色，打开角色信息。
2. 点击已装备的物品，查看装备详情。
3. 点击「3D 预览」，拖动角色并切换全身和面部，确认场景和贴图已加载。
4. 点击「导出 PNG」，检查 WebView2 下载的 880 × 1200 PNG。

前端、样式和渲染器来自随开发任务提供的参考源码。Windows 字体使用系统回退，场景和贴图通过 C# 处理的 HybridWebView 虚拟资源读取。运行时无需启动额外服务。

## 检查游戏版本

在「设置 → 高级设置」检查官方修复清单。客户端自动读取 EXE 的大小和 SHA-1 及现有资料片的版本文件，以生成 Lobby 使用的版本字段。当前修复入口对应参考代码的国服发行渠道 `8847`。首次检查需要联网下载 EXE 字节用于流式哈希，无需安装或执行游戏。再次检查同一清单时会使用本地缓存。

「大厅服务器版本」是单独保存的协议值，默认采用参考客户端的 `7500`，输入范围为 0 至 65535。该值已用于本次国服测试，今后可随游戏协议更新调整。

## 盛趣登录与社区验证

客户端启动后打开「首页」，可直接查看艾欧泽亚时间、石之家活动日历和国服官方信息。通过「设置 → 账号绑定 → 登录」选择官方大区，使用叨鱼确认或二维码授权。首次登录需要选择角色。有多个服务账号时，先选服务账号，再读取该账号的角色列表。客户端按盛趣账号和大区分别保存 Lobby 角色数据及当前角色。恢复已保存的登录后，首页会显示上次选择的角色。「设置」里的「当前角色」位于「账号绑定」下方，可以切换角色或刷新角色信息。

角色资料中的生日和守护神来自 Lobby 的角色选择数据。旧缓存可通过「刷新角色信息」补齐这两项。 [ClientSelectData 字段](https://github.com/redstrate/Kawari/blob/master/servers/world/src/client_select_data.rs)

手动登录后，客户端会尝试为石之家单独换票。勾选「在此设备保存登录状态」时，会保存已验证的石之家凭据。再次打开会直接读取本地角色，使用已有凭据更新职业等级；需要更新 Lobby 数据时可手动点击「刷新角色信息」。清除保存的登录状态会同时删除本地保存的游戏和石之家凭据。

## 预览游戏角色

首次打开角色信息时，客户端从官方修复 CDN 按需读取 SqPack，用 C# 生成模型与贴图，并保存全身与面部静态肖像。后续打开角色信息会使用缓存。「3D 预览」可以查看并旋转角色，退出 3D 会恢复静态肖像。需要更新游戏外观、装备或 Lobby 角色资料时，在设置页选择「刷新角色信息」。刷新成功后会重新打开角色信息并生成预览。

装备详情按外观模型和变体展示参考物品。名称、图标编号、品级、装备要求、属性、染色、服务器名称和守护神来自 XIVAPI 的简体中文 EXD 数据。客户端内置快照供离线查询。图标像素、模型和贴图由客户端按需从官方 CDN 获取。 [XIVAPI 表格文档](https://xivapi-v2.xivcdn.com/zh-cn/docs/guides/sheets/)

## 天气查询

在主导航打开「天气」，按地区和地图查看未来 48 个现实小时的天气。预报表按 ET 00:00、08:00 和 16:00 分列，每个时段的现实时间均按北京时间显示。可以组合筛选天气、前置天气和艾欧泽亚小时。

地图、天气概率和天气图标来自简体中文 XIVAPI。客户端内置数据快照，打开页面时根据当前时间在本机计算预报。 [XIVAPI 表格文档](https://xivapi-v2.xivcdn.com/zh-cn/docs/guides/sheets/)

## 更新游戏数据

在「设置 → 高级设置」点击「更新游戏数据」。客户端从 XIVAPI 下载简体中文角色、装备、地图和天气表，以及天气图标。校验所有表的版本一致后，客户端会把新快照保存到本机并立即使用。下载失败时继续使用当前快照，首次使用也可以离线查询内置数据。 [XIVAPI 表格文档](https://xivapi-v2.xivcdn.com/zh-cn/docs/guides/sheets/)

要刷新随程序发布的内置快照，在仓库根目录运行以下命令，再运行 Windows 构建脚本。

```powershell
dotnet run --file scripts/update-exd-data.cs
```

脚本和客户端共用同一个导入器。内置快照保存在 `data/exd/zh-cn.json.gz`。
